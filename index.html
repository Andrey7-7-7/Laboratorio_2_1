Objetivo del laboratorio

El objetivo de este laboratorio es preparar un ambiente básico para el desarrollo web mediante la instalación y configuración de diferentes herramientas tecnológicas.

Durante el laboratorio se utilizan navegadores web, Visual Studio Code, Git y GitHub para crear, probar y administrar un proyecto de desarrollo web.

Herramientas utilizadas

Microsoft Edge
Google Chrome
Mozilla Firefox
Visual Studio Code
Git
GitHub

Desarrollo Web

HTML permite estructurar el contenido de una página web. Visual Studio Code facilita la escritura y edición del código mediante funciones como el resaltado de sintaxis y el autocompletado.

Git permite realizar un seguimiento de los cambios realizados en el código, mientras que GitHub permite almacenar y administrar los repositorios de los proyectos.

Conclusión

La utilización de navegadores, herramientas de desarrollo y sistemas de control de versiones permite establecer un entorno adecuado para crear, probar y administrar proyectos web.
